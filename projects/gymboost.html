Project Overview

Digitizing gym operations

GymBoost replaces manual, paper-based registration and attendance tracking with an RFID-powered digital workflow. Members check in with an RFID tag instead of signing a logbook, and staff manage registration, attendance, and day-to-day operations through a centralized admin dashboard.

The system connects a PHP/MySQL backend to a Bootstrap-based frontend and admin interface, with JavaScript handling interactive behavior across both.

Key Features

What the system does

RFID-Powered Attendance

Members use RFID for faster, more efficient attendance tracking, replacing manual attendance processes.

Digitized Registration

Converts the traditional manual registration workflow into a fully digital process.

Administrative Dashboard

Administrators manage gym operations — members, attendance, and records — through a centralized dashboard.

Full-Stack Architecture

Connects the frontend interface, backend logic, and MySQL database into one functional system.
